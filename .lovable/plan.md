## 2. leonforge

| Показатель | Значение |
| --- | --- |
| Клики / расход | 120 / $46,6 (бюджет $5/день) |
| Заявки в Google | 0 |
| Потери из-за рейтинга | 85% (было 69%) |
| Потери из-за бюджета | 2% |
| Объявления | 2, одобрены, сила «Средняя», обе ведут на главную |

**Откуда снова «лендинг»:** ключи «сайты лендинги» (25 кликов, $9,8) и «сайт лендинг» (15 кликов, $5,7) дают больше трети расхода и ловят «лендинг», «landing pages», «лендінг пейдж». Хорошие ключи: «купити сайт» (11), «створення сайтів» (13), «створення сайту», «розробка сайту».

**Почему показы такие редкие:** у многих ключей оценка 1–3 из 10. Google считает, что объявление и главная страница не подходят под запрос. Из-за этого объявления мало показываются, хотя бюджет почти весь доступен.

**Предлагаю (2 карточки):**
1. Пауза 2 ключей: «сайты лендинги» и «сайт лендинг». Плюс пауза ключей с оценкой 1/10: замовити дизайн сайту, developer website, hire web developer, web master, разработка веб приложений, создание сайтов одесса.
2. 4 фразовых минус-слова: landing pages, landing page, лендінг пейдж, ідеї.

**Вне рекламы (проект leonforge):** главное, что поднимет рейтинг, — улучшить объявления и сделать отдельные страницы под «створення сайту» и «сайт для бізнесу за кордоном». Сюда же Consent Mode для учёта заявок.

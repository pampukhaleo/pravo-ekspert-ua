# Заміна Telegram токена

## Контекст
Контактна форма (`supabase/functions/contact-form/index.ts`) читає секрет `TELEGRAM_BOT_TOKEN` (токен бота) для відправки повідомлень у Telegram. Секрет вже існує — треба замінити його значення новим.

## Що робимо
1. Викликати `update_secret` для `TELEGRAM_BOT_TOKEN` — відкриється безпечна форма, де користувач введе нове значення.
2. Після збереження переконатися, що edge-функція `contact-form` підхопила новий токен (вона читає його через `Deno.env.get` при кожному запиті — додаткове розгортання не потрібне, але можна перевірити тестовим викликом).

## Що НЕ змінюємо
- `TELEGRAM_CHAT_ID` залишається як є.
- Код edge-функції не змінюється.
- Ніяких змін у фронтенді чи контактній формі.

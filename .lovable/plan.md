# Заміна Telegram токена та Chat ID

## Контекст
Контактна форма (`supabase/functions/contact-form/index.ts`) читає два секрети:
- `TELEGRAM_BOT_TOKEN` — токен бота
- `TELEGRAM_CHAT_ID` — ID чату куди надсилаються повідомлення

Обидва секрети вже існують у проєкті. Користувач хоче їх замінити новими значеннями.

## Що робимо
1. Викликати `update_secret` для `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID` — відкриється безпечна форма, де користувач введе нові значення.
2. Після збереження секретів переконатися, що edge-функція `contact-form` підхопить нові значення (вона читає їх через `Deno.env.get` при кожному запиті — додаткове розгортання не потрібне, але можна перевірити через тестовий виклик).

## Що НЕ змінюємо
- Код edge-функції залишається як є — він вже посилається на `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`.
- Ніяких змін у фронтенді чи контактній формі.

# leonforge: почему нет заявок и что делаем

## Что показала проверка (22.09, последние 7 дней)

- 1289 показов, 74 клика, ~$25, заявок 0. Клик $0,34 — дешевле потолка.
- **Главный слив: 28 из 74 кликов ($8 из $25 — треть бюджета!) уходит на один голый запрос «сайт»** — его даёт широкий ключ «web сайт». Это люди без понятного намерения.
- Второй пласт мусора всё ещё проходит: «сайт купить», «купити сайт», «лендінг приклад», «сайт визитка пример», «стили сайтов», «красивые сайты» — люди ищут примеры и покупку готового, а не разработку.
- Есть и хорошие сигналы: «створення сайту під ключ», «розробка сайту тернопіль», «сколько стоит сделать сайт в польше» (это как раз диаспора!), «дизайн сайта цена».
- Минус-слова, добавленные 21.09, работают — «darknet», «гугл sites» исчезли; часть мусорных кликов набежала до чистки.

Вывод: бюджет сливает не отсутствие спроса, а широкий ключ «web сайт», который тащит голый «сайт». 0 заявок при таком трафике — ожидаемо, а не признак провала.

## Что предлагаю сделать сейчас

1. **Усмирить ключ «web сайт»** — главный источник слива (28 кликов на «сайт»). Два варианта на выбор:
   - A (рекомендую): перевести его в фразовое соответствие — запрос должен содержать «web сайт» целиком, голый «сайт» отсечётся.
   - B: поставить на паузу совсем — останутся только точные целевые ключи.
2. **Добавить минус-слова второй волной**: купить, купити, html, css, front end, frontend, shopify, readymag, framer, mobirise, visit site, visit site.
3. **Добавить фразовые ключи под реальные запросы, которые уже приходили**: «створення сайту під ключ», «розробка сайту», «замовити сайт», «сайт для бізнесу», «створення сайту для бізнесу» — чтобы покупать именно их, а не «сайт».

Бюджет $5/день, стратегию, объявления и географию (Украина + диаспора) не трогаю.
